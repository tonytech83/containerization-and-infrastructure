### T303
1. Create roles folder hierarchy
```sh
mkdir -pv ~/tasks/t303/roles/application2/{handlers,tasks,vars}
```
2. Create main.yaml in each folder of role
```sh
touch ~/tasks/t303/roles/application2/{handlers,tasks,vars}/main.yaml
```
3. Create inventory
```sh
t202-1 ansible_host=192.168.99.202 ansible_port=10204 
t202-2 ansible_host=192.168.99.202 ansible_port=11204

[all:vars]
ansible_user=root
ansible_ssh_private_key_file=~/.ssh/id_rsa
```
4. Create ansible.cfg
```sh
[defaults]
inventory=inventory.ini
host_key_checking = False
```
5. Create /rules/application2/tasks/redhat.yaml
5. Create /rules/application2/tasks/debian.yaml
5. Create /rules/application2/tasks/common.yaml
5. Create /rules/application2/tasks/main.yaml
6. Create playbook.yaml
7. Run the playbook
```sh
ansible-playbook playbook.yaml
```
8. Test web app on both hosts
```sh
curl http://192.168.99.202:20204
curl http://192.168.99.202:21204
```
